# oaqi-final-project-emotion-detection
# Detector de Emociones

Aplicación web de detección de emociones desarrollada con Python, Flask y la
biblioteca Watson NLP de IBM.

El sistema recibe un texto, lo envía al servicio EmotionPredict de Watson NLP y
devuelve las puntuaciones de cinco emociones —anger, disgust, fear, joy y
sadness— junto con la emoción dominante.

Proyecto final del curso *Developing AI Applications with Python and Flask*.
